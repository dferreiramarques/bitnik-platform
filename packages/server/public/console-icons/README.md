# Ícones do menu da consola

Um SVG por secção, com o nome da secção. Ficam aqui e a consola usa-os sozinha:

| Secção | Ficheiro |
| --- | --- |
| Painel | `painel.svg` |
| Jogos | `jogos.svg` |
| Mesas de aprovação | `mesas.svg` |
| Avisos | `avisos.svg` |
| Aparência | `aparencia.svg` |
| Marcas | `marcas.svg` |
| Forge | `forge.svg` |

Regras: `viewBox="0 0 24 24"`, uma só cor (qualquer; a consola pinta-os com a cor do texto), formas com traço ou preenchimento, sem texto nem imagens embebidas. Hoje todos são o mesmo quadrado, de teste.
